# content/

Drop your problem-set `.json` files here, then ingest one with:

```bash
npm run push content/your-set.json
```

(You can keep them anywhere — this folder is just the conventional spot. The
path you pass to `npm run push` can be absolute or relative.)

For the format, see [../docs/PROBLEM-SET-SCHEMA.md](../docs/PROBLEM-SET-SCHEMA.md).

Prefer not to touch the terminal? Use the **Problem sets → Upload** control on
the tutor dashboard instead — same validation and figure rendering, in the
browser, against whatever environment the dashboard is running on.
